# DataUpdatePage (עדכון פירוט שמי)

העמוד המרכזי לעדכון סטטוס נוכחות יומי עבור חיילי היחידה. דף זה מיועד למפקדים ומאפשר שינוי מהיר של מצב החייל (בבסיס, בבית, גימלים וכו').

## Purpose
- ניהול נוכחות יומית בזמן אמת.
- סנכרון ישיר מול גיליון הרישום של ה-Google Sheets דרך n8n.
- מתן תמונת מצב מדויקת לשיבוצי חפ"ק ושמירות.

## Key Components
- **Header with DatePicker**: בחירת התאריך עבורו מתבצע העדכון. כברירת מחדל מציג את היום הנוכחי.
- **Search & Filter Bar**: חיפוש לפי שם וסינון לפי מחלקות (דינמי לפי הנתונים המגיעים).
- **Attendance Table**: טבלה המרכזת את כל החיילים עם האפשרות לעדכן סטטוס דרך Dropdown מעוצב.
- **Status Options**: אפשרויות סטטוס מוגדרות מראש (בבסיס, בבית, מחלה, חוזר, יוצא).

## State Management
- `date`: תאריך העדכון (ISO string).
- `search`: מחרוזת החיפוש.
- `deptFilter`: המחלקה הנבחרת לסינון.
- `updatingId`: מזהה החייל שבתהליך עדכון (למניעת כפילויות והצגת Loading מקומי).

## Core Logic & Data Flow
- **Data Fetching**: משתמש ב-`useMainAttendance(date)` (React Query) למשיכת הנתונים.
- **Normalization**: פונקציית `normalizeValue` ממירה את הנתונים המשונים מהגיליון (V, 1, 0, גימלים) לקודים סטנדרטיים של המערכת.
- **Updates**: שליחת בקשת POST ל-`UPDATE_API` (Webhook של n8n) עם שם החייל, הסטטוס החדש והתאריך. לאחר הצלחה, מתבצע `refetch` לנתונים.

## Permissions
- השימוש בעמוד זה מוגבל למשתמשים בעלי הרשאת `update` דרך ה-`CommanderGuard`.
